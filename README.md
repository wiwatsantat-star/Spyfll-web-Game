# Spyfall Thailand V5 — 300 Locations

โปรเจกต์พร้อมใช้งานกับ GitHub และ Render

## ฐานข้อมูลเกม

- 300 สถานที่ ใช้สุ่มอัตโนมัติ
- 30 หมวด หมวดละ 10 สถานที่
- ชื่อสถานที่เป็นชื่อสถานที่ล้วน ๆ
- ไม่มีเหตุการณ์ เวลา หรือคำอธิบายต่อท้ายชื่อสถานที่
- 15 บทบาทต่อสถานที่
- 4,500 รายการบทบาทรวม
- บทบาทมีทั้งแบบปกติ แบบเฉพาะอาชีพ และแบบคาดไม่ถึง

## ตัวอย่างชื่อสถานที่

- ไซต์ก่อสร้าง
- ห้องฉุกเฉิน
- ร้านหมูกระทะ
- สถานีรถไฟ
- งานวัด
- โรงงาน
- บ้านเพื่อน
- ปั๊มน้ำมัน
- ศาลจังหวัด
- ศูนย์ข้อมูล

## รันในเครื่อง

```bash
npm install
npm start
```

เปิด `http://localhost:3000`

## Deploy บน Render

- Runtime: Node
- Branch: main
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: เว้นว่าง

ตรวจระบบที่ `/health`


## การตั้งค่า Host เวอร์ชัน V6

- Host ไม่เห็นรายชื่อสถานที่
- Host ไม่ต้องเลือกสถานที่
- ระบบสุ่มจากสถานที่ทั้งหมด 300 แห่ง
- มีตัวเลือกเปิดหรือปิดรายการช่วย Spy
- เมื่อเปิด Spy จะเห็น 30 สถานที่
- เมื่อปิด Spy จะไม่เห็นรายการสถานที่


## ตารางคะแนน V7

- ผู้เล่นทุกคนเห็นตารางคะแนน
- เรียงผู้เล่นจากคะแนนสูงสุด
- Host เพิ่มคะแนน +1 หรือลดคะแนน -1 ได้
- Host รีเซ็ตคะแนนผู้เล่นทั้งหมดได้
- คะแนนคงอยู่ระหว่างการเล่นหลายรอบในห้องเดียวกัน
